Dial: A Knowledge-Grounded Dialect-Specific NL2SQL System

针对跨数据库代码生成中的知识幻觉、方言干扰与不可执行问题，构建知识增强的闭环 Agent Workflow，在无需模型微调的情况下实现跨环境代码生成。A knowledge-grounded, closed-loop agent workflow for cross-database code generation that addresses knowledge hallucinations, dialect interference, and non-executable outputs without model fine-tuning.

+10.25%执行准确率Execution accuracy
+15.77%方言特征覆盖率Dialect feature coverage
2,218测试样例 · 6 个数据库Test cases · 6 databases
研究细节与实验Methods & evaluation
  • 闭环工作流：整合规划、检索、生成、执行反馈与语义校验，提升跨数据库生成的可执行性。
  • 推理与知识增强：设计 NL-LQP，将自然语言需求分解为具有依赖关系的 DAG Macro-Operators；构建分层知识库 HINT-KB，从官方文档组织函数知识与隐式执行约束，提供面向意图的 Structured RAG。
  • Agent 自修复：设计 Execution-Driven Debugging，根据真实执行反馈检索约束并定向修复；以 Logical Plan 进行语义校验，避免 Semantic Drift，并将验证后的经验持续回写知识库。
  • 实验：构建覆盖 6 个数据库、2,218 个测试样例的 DS-NL2SQL Benchmark；相比最强标准 Baseline，Execution Accuracy 平均提升 10.25%，Dialect Feature Coverage 平均提升 15.77%。
  • Closed-loop workflow: combines planning, retrieval, generation, execution feedback, and semantic validation to improve the executability of cross-database outputs.
  • Reasoning and knowledge grounding: designed NL-LQP to decompose natural-language requests into DAG macro-operators with dependencies, and HINT-KB to organize function knowledge and implicit execution constraints from official documentation for intent-oriented structured RAG.
  • Agent self-repair: designed execution-driven debugging to retrieve constraints and make targeted repairs from actual execution feedback; used logical plans to prevent semantic drift, and continuously wrote validated experience back to the knowledge base.
  • Evaluation: built the DS-NL2SQL benchmark with 2,218 test cases across 6 databases. Compared with the strongest standard baseline, improved average execution accuracy by 10.25% and dialect feature coverage by 15.77%.

AutoDialect: Automating SQL Dialect Rule Generation with LLMs

让 LLM Agent 从 SQL 样例中自动生成、验证并持续集成可复用的代码级规则，减少通用 Coding Agent 对单个样例的过拟合。An LLM-agent approach that automatically generates, validates, and continuously integrates reusable code-level rules from SQL examples, addressing overfitting to individual examples in general-purpose coding agents.

+35.2%平均准确率提升Average accuracy gain
360经过验证的代码级规则Validated code-level rules
9SQL 方言SQL dialects
研究细节与实验Methods & evaluation
  • 结构化 Agent 推理：设计 Shared-Tree 与 Context-Complete SQL Unit，定位复杂输入中的多个变换需求并构造结构完整的生成单元；通过结构对齐的 Validation Variants 提升跨样例泛化能力。
  • 代码生成与记忆：将开放式 Explore–Edit–Test 重构为 Stage-Based Generation，结合 Validation Gate、Failure-Scoped Repair 与 Trajectory / Working / Cross-Task Memory，实现可验证的生成、自修复和跨任务经验复用。
  • 实验：在两个真实工业项目及覆盖 9 种 SQL Dialect 的公开数据集上，相比现有方法和 Claude Code、Codex 等 Coding Agent，准确率平均提升 35.2%，生成 360 个经过验证的代码级规则。
  • Structured agent reasoning: designed Shared-Tree and Context-Complete SQL Units to locate multiple transformation needs in complex inputs and construct structurally complete generation units; improved cross-example generalization with structurally aligned validation variants.
  • Code generation and memory: replaced open-ended Explore–Edit–Test with stage-based generation, combining validation gates, failure-scoped repair, and trajectory / working / cross-task memory for verifiable generation, self-repair, and experience reuse across tasks.
  • Evaluation: on two real industrial projects and a public dataset covering 9 SQL dialects, improved average accuracy by 35.2% over existing methods and coding agents such as Claude Code and Codex, producing 360 validated code-level rules.

面向长程 LLM Agent 的记忆系统调研与评测Survey and evaluation of memory systems for long-horizon LLM agents

Memory SystemsData ManagementEvaluation
  • 体系化调研：针对上下文膨胀、历史检索与知识冲突，从 Data Management 视角将 Agent Memory 拆分为 Storage、Extraction、Retrieval、Maintenance，系统梳理 Vector、Structured、Knowledge Graph 与 Hybrid Memory 架构。
  • 评测与总结：建立统一比较框架，从 Retrieval、Dynamic Update、Long-Horizon Stability 与 Cost 维度分析主流 Memory System，总结 Incremental Update、Conflict Resolution、Selective Forgetting 与 Memory-to-Action 等开放问题。
  • Systematic survey: examined context growth, history retrieval, and knowledge conflicts from a data-management perspective, decomposing agent memory into storage, extraction, retrieval, and maintenance; reviewed vector, structured, knowledge-graph, and hybrid architectures.
  • Evaluation and synthesis: established a unified comparison framework for retrieval, dynamic updates, long-horizon stability, and cost; identified open problems in incremental updates, conflict resolution, selective forgetting, and memory-to-action.
