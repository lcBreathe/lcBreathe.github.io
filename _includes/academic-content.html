MemTrace: State-Consistent Memory for Long-Horizon Coding Agents

Hongming Xu, Le Zhou, ZhongHe Jin, Xiang Zhang, Bo Tang, Zhiyu Li, Xuanhe Zhou, Juncheng Zhang

ICLR在审Under review2026.10

MemTrace 研究长程 Coding Agent 在上下文刷新后如何恢复记忆，同时保持记忆与当前代码状态一致。它用不可变的 Memory Traces 和 Memory Trace Graph 保留执行历史，再根据当前仓库状态校验历史证据，避免恢复已经失效的信息。

在相同 backbone 和 harness 下，论文报告 Codex CLI 在三个长程编码基准上的提升：DeepSWE pass@1 +21.2 个百分点，SWE-EVO Resolved Rate +4.4 个百分点，SWE-Milestone Score +17.8 个百分点。

MemTrace studies how long-horizon coding agents can recover memory after a context refresh while keeping it consistent with the current code state. Immutable memory traces and a memory trace graph preserve execution history; validation against the current repository state checks that recovered evidence is still valid.

With the same backbone and harness, the paper reports gains under Codex CLI on three long-horizon coding benchmarks: +21.2 percentage points in DeepSWE pass@1, +4.4 points in SWE-EVO Resolved Rate, and +17.8 points in SWE-Milestone Score.

Dial: A Knowledge-Grounded Dialect-Specific NL2SQL System

Xiang Zhang, Hongming Xu, Le Zhou, Wei Zhou, Xuanhe Zhou, Guoliang Li, Yuyu Luo, Changdong Liu, Guorun Chen, Jiang Liao, Fan Wu

PVLDB 2026第一作者First author2025.07 — 2026.03

Dial 面向不同数据库的 SQL 方言，将规划、检索、生成、执行反馈和语义校验串联起来，无需模型微调即可生成跨环境代码，减少知识幻觉、方言干扰和不可执行的输出。NL-LQP 把自然语言需求分解为带依赖关系的 DAG Macro-Operators；分层知识库 HINT-KB 从官方文档整理函数知识与隐式执行约束，为各个步骤提供面向意图的 Structured RAG。

生成后，系统根据真实执行反馈检索约束并定向修复，用 Logical Plan 检查语义偏移（Semantic Drift），再将验证后的经验写回知识库。我们构建了覆盖 6 个数据库、2,218 个样例的 DS-NL2SQL Benchmark；相比最强标准 Baseline，执行准确率平均提升 10.25%，方言特征覆盖率平均提升 15.77%。

Dial combines planning, retrieval, generation, execution feedback, and semantic validation to generate SQL across database dialects without model fine-tuning, addressing knowledge hallucinations, dialect interference, and non-executable outputs. NL-LQP decomposes a natural-language request into DAG macro-operators with dependencies. The hierarchical HINT-KB organizes function knowledge and implicit execution constraints from official documentation to support intent-oriented structured RAG.

The system retrieves constraints and makes targeted repairs using actual execution feedback, checks logical plans for semantic drift, and writes validated experience back to the knowledge base. We built DS-NL2SQL with 2,218 test cases across 6 databases. Compared with the strongest standard baseline, Dial improves average execution accuracy by 10.25% and dialect feature coverage by 15.77%.

面向长程 LLM Agent 的记忆系统调研与评测Survey and evaluation of memory systems for long-horizon LLM agents

针对长程 LLM Agent 的上下文膨胀、历史检索和知识冲突，从数据管理角度梳理记忆系统的 存储、提取、检索与维护，比较向量、结构化、知识图谱和混合记忆架构。

建立统一比较框架，从检索、动态更新、长程稳定性和成本四个维度分析主流系统，整理增量更新、冲突消解、选择性遗忘和 Memory-to-Action 等开放问题。

Surveyed memory systems for long-horizon LLM agents facing context growth, history retrieval, and knowledge conflicts. From a data-management perspective, organized the field around storage, extraction, retrieval, and maintenance, comparing vector, structured, knowledge-graph, and hybrid architectures.

Established a shared comparison framework covering retrieval, dynamic updates, long-horizon stability, and cost; identified open questions in incremental updates, conflict resolution, selective forgetting, and memory-to-action.

大规模图学习与 GNN–LLM 融合Large-scale graph learning and GNN–LLM fusion

Extended experiments to ogbn-products (over 2.45 million nodes and 61.86 million edges), using GraphSAGE neighbor sampling for mini-batch training to reduce memory and computation costs.

Combined graph structure and LLM text representations using BiGTex graph-text fusion with LoRA, achieving the best test performance among the compared models on ogbn-products.
